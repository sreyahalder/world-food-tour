# World Food Tour typography

Bricolage Grotesque is used for headings through the existing --serif token. DM Sans is used for body text and controls through --sans and --ui. Headings use weight 600, and the title uses weight 650 with natural mixed-case letterforms instead of synthetic small caps. Existing type sizes and layout spacing are retained. The font declarations are imported by globals.css so they travel with the main stylesheet during live updates as well as production builds.
